# [Servis] Bölüm 360°: özet, maskeli iletişim ve görüntüleme kaydı, bölüm süzgeçleri, hane üyeleri

Kaynak: Yazılım Dokümanı **YAP-03** (Bölüm 360° kartı), **YAP-04** S4 (hane üyeleri).

## Ekran
- **Bölüm kartı** (`/daireler/{id}`): üstte bakiye, malik hisse toplamı, araç, hane üyesi, bekleyen kargo; uyarılar
  (malik yok, hisse eksik, arsa payı yok); hızlı eylemler (düzenle, satış/veraset, talep aç, tahsilat kaydet).
  Sekmeler: **Kişiler** (maskeli iletişim + "Göster", hane üyeleri), **Finans** (gerçek `accounts?unit_id`),
  **Talepler** (`requests?unit_id`), **Araçlar** (istek 22), **Güvenlik** (`packages?unit_id`, `visitors?unit_id`),
  **Özel alanlar** (istek 24), **Geçmiş** (`audit?entity=units`, öznitelik geçmişi).
- **Kişiler** (`/kisiler`) listesinde de iletişim maskeli.
- **Sakin → Hane üyeleri** (`/sakin/{slug}/hane`): davet, yetki, bitirme.

## Uç nokta
- `GET  /api/v1/sites/{slug}/units/{id}/overview`
- `POST /api/v1/sites/{slug}/people/{id}/contact-views` — kişisel veriyi açma; **denetim kaydı yazar**
- `GET  /api/v1/sites/{slug}/requests?unit_id=` ve `GET …/visitors?unit_id=` — mevcut uçlara süzgeç
- Hane üyeleri (personel): `GET/POST …/units/{id}/household`, `PATCH …/household/{id}`, `POST …/household/{id}/end`
- Hane üyeleri (sakin): `GET/POST …/resident/household`, `POST …/resident/household/{id}/end`

## İstek / yanıt
Özet:
```json
{ "balance": "1250.00", "share_total": "100.00", "warnings": ["no_land_share"],
  "packages_waiting": 1, "vehicles": 2, "household": 1 }
```
`warnings`: `no_owner | shares_incomplete | no_land_share`.

İletişim görüntüleme — **öneri:** listeler telefon/e-postayı maskeli döner (`+90 532 *** ** 33`, `a***@ornek.com`);
`POST …/contact-views` açık değeri döner ve denetim kaydına `contact_view` yazar:
```json
{ "data": { "phone": "+905321112233", "email": "test.deneme@ornek.com" }, "message": null }
```
(Frontend şimdilik maskeyi kendi tarafında uyguluyor ve 204 bekliyor; servis gelince maskeli alanlara geçilir.)

Hane üyesi:
```json
{ "full_name": "Test DENEME", "phone": "+905321112233",
  "permissions": { "visitors": true, "packages": true, "reservations": false, "requests": false } }
```
Yanıt: + `id`, `unit_id`, `unit_name`, `invited_by`, `status` (`invited | active | ended`), `invite_link`
(`/davet/{token}`), `created_at`, `ended_at`. Sakin ucunda `unit_id` isteğe bağlı (çok bölümlü sakin için).

## İş kuralları
- **KVKK veri minimizasyonu (YAP-03 S2):** telefon/e-posta varsayılan maskeli; açma işlemi kim/ne zaman/hangi kişi ile
  denetim kaydına yazılır. Güvenlik rolü kişisel veriyi hiç göremez (mevcut `units/lookup` kuralı korunur).
- `overview.balance`: bölümün açık cari hesaplarının bakiye toplamı; `share_total` yürürlükteki maliklerin hisse toplamı.
- Hane üyesi: bölüm başına en fazla **6** etkin üye; aynı telefonla ikinci üye 409. Davet kabul edilince `active`.
  Hane üyesi borç/ekstre göremez; yetkileri yalnız ziyaretçi, kargo, rezervasyon, talep. Sakin yalnız kendi bölümüne
  ekler; personel `people.manage` ile her bölüme.
- SMS yok (K5): davet bağlantısı ekranda kopyalanır. Davet kabulü istek 23'teki `public/invitations/{token}` akışıyla aynı.
- Bitirme silmez; `ended` olarak geçmişte kalır.

## Hata durumları
| Durum | Kod | Mesaj |
|---|---|---|
| Alan hatası | 422 `fields.full_name/phone` | "Formda düzeltilmesi gereken alanlar var." |
| Üye sınırı | 409 `household_limit` | "Bu bölümde en fazla 6 hane üyesi olabilir." |
| Aynı telefon | 409 `already_member` | "Bu telefonla hane üyesi zaten var." |
| Zaten bitmiş | 409 `already_ended` | "Hane üyeliği zaten bitmiş." |

## Yetki
Özet ve süzgeçler: ilgili modülün okuma izni (`units.read`, `finance.read`, `requests.read`, `security.*`).
`contact-views`: `people.read`. Hane (personel): `people.manage`. Hane (sakin): oturum sahibi sakin.

## Kabul kriterleri
- [ ] Maskeli alan açıldığında denetim kaydında `contact_view` (kullanıcı, kişi, zaman) görünür
- [ ] `requests?unit_id` ve `visitors?unit_id` yalnız o bölümü döner, sayfalama korunur
- [ ] 7. hane üyesi 409; bitirilen üye sınırı doldurmaz
- [ ] Sakin başka bölüme hane üyesi ekleyemez (404)
